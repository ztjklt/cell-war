# 细胞战争

TapTap Maker 原创单人生存 RTS。你指挥微小的细胞群落，在一个巨大的虚构人体内部采集营养、建立胞巢、探索器官并与两个敌方胞群作战。地图保留暗色手绘风、1024×1024 规模、战争迷雾与长期沙盒规则。横屏手机优先，兼容电脑键鼠。

项目 ID：`99c42b81-6612-4d02-a15a-1efa4bf0eebf`。入口：`scripts/main.lua`。运行于 Maker Lua 5.4、NanoVG 与原生 `urhox-libs/UI`。未执行远端提交或构建。

## 试玩

点击「建立胞群」。按 M 或点击「地图」，再切换「组织总览」查看人体内域；点击全图定位镜头，「返回胞群」返回当前核心。总览不显示未探索敌方，关闭地图后世界仍受迷雾限制。

第一天先选择工细胞，点击蛋白束、钙晶或胶原束采集。物资运回核心胞巢或储运囊后才进入共享库存。补建荧光腺、培养床和栖息泡，再发展分裂兵巢与核酸研究站。游走细胞探索血管沿线，远征需要前哨储运囊补给。

## 体内世界

地图共 1,048,576 格，约为初版面积的 28.4 倍。脑域和肺泡区位于上方，心脏与肝域位于胸腹部，肠道向下盘绕，骨质与骨髓沿肢体展开。器官位置保持可识别结构，局部边界、病灶及资源由种子生成。血管分支连接组织区与三个出生点，血浆深流无法步行。

16 种组织地貌：疏松结缔组织、肌纤维束、骨质矿脊、淋巴湿地、神经突触林、脂肪储能层、肺泡气囊群、真皮屏障、肝叶营养区、软骨缓冲带、肠道菌群林、坏死组织荒原、毛细血管道、血浆深流、骨髓增殖池、炎症热区。组织拥有不同资源分布、颜色和绘制细节；湿地减速、炎症增加热压力，血管有移动加成及脉动效果。

八种资源：蛋白质、钙质、盐晶、胶原、铁质、葡萄糖、脂质、基因片段。六类可控制细胞：工细胞、游走细胞、刺膜细胞、毒囊细胞、甲壳细胞、巨噬细胞。每阵营人口上限 40，巨噬细胞占两人口，训练队列预留人口。

十四种可建造结构使用原创膜囊外观，包括核心胞巢、储运囊、栖息泡、荧光腺、营养转化池、培养床、核酸研究站、分裂兵巢、毒囊孵化池、巨噬孵化池、修复腺、膜壁、膜门和防御触须塔。工细胞负责施工、培育、修复和灼伤处理；取消未完成结构返还 75% 材料。

原六分钟昼夜循环改以活跃、过渡、休息表达，比例仍为 60%、15%、25%；原四季参数改为平衡、低代谢、复苏、高代谢，每期八天。细胞独立计算生命、饱食、温度、精神与潮湿，荧光腺消耗脂质，补给建筑供给葡萄糖，营养按批次腐败。这是以人体为灵感的幻想地图与生存规则。

两个 AI 使用相同资源、迷雾、人口与生产规则，自主发展、侦察、研究、进攻、撤退和重建。摧毁敌方核心、工细胞及生产能力后获胜，可继续沙盒；己方核心丢失仍能利用幸存工细胞重建。

## 存档与性能设计

三个手动槽及一个每次新日自动保存槽接入 Maker `clientCloud`。以成功回调后的「已保存」为准；失败与超时保留实时游戏及待重试快照。**当前本地云服务未连接，退出或刷新会丢失未成功保存的进度。**

存档 v3 保存地图类型、种子、随机数、时间、已生成区块、资源变化、实体、库存、科技、稀疏迷雾、命令和 AI 状态。新游戏使用人体组织地图；读取 v1 / v2 保留旧地图拓扑、营地与探索进度，采用新的细胞及组织美术，不把旧基地搬到新器官位置。

资源与感染巢按 32×32 区块随探索生成，地形按需缓存；视口裁剪、八格空间桶和稀疏小地图减少遍历。远距离路径使用 16 格宏观网格及分段局部 A*，每模拟步最多处理 500 个节点。前台渲染上限 60 FPS，失去焦点时上限 30 FPS。玩法维持每秒 10 次固定模拟；画面按每帧剩余时间插值，并沿真实分段路径移动，点击与框选使用相同显示位置。细胞短促加速、临近目标减速，跨路径点继续消耗本步移动距离，减少走停和拥挤抖动。细胞膜、组织脉动、毛细血管和漂浮红细胞使用连续模拟时间，暂停时冻结。组织颜色在相邻格之间过渡，地表叠加跨格膜层和连贯微血管，着色缓存有固定容量。

本地开发需要 TapTap Maker CLI 和配套的 UrhoX 开发包；引擎库由 Maker 提供。获取项目后在项目根目录运行：

```sh
git clone https://github.com/ztjklt/cell-war.git
cd cell-war
taptap-maker preview start --target-dir "$PWD" --json
```

修改代码后查询 `preview status`，只对运行中会话执行 `preview refresh`。刷新会重置未保存进度，已关闭的预览不会自动重启。开发包、引擎文档与 `urhox-libs/` 不作为游戏源码提交。手机真机手感、30 FPS、真实云跨会话保存及当前版本两轮长期周期仍需对应环境验收。
