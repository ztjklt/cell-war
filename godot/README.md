# 细胞战争 · Godot 重构版

使用 Godot **4.6+ 标准版 / GDScript / 2D**。本次以原工作区的实际代码与素材为迁移依据，包括未提交的修改。Lua 旧版已于 2026-10-20 按用户要求归档清理；本目录是独立 Godot 工程，运行不依赖 Lua、Python、UrhoX、Maker 或网络。

2026-10-20：首页采用用户确认的新结构主义静态角色插画，保留左侧三个正派，在右侧粉紫、青蓝病毒之外融入黄绿色细菌反派；已取消角色待机动画和眼睛跟随。默认启动先显示封面，“开始作战”打开新建／继续存档选择，新建从左肺上部防线开始；2026-10-21 将故事入口改为“角色预览”，查看角色与地图，教学入口保留现有指引。素材与验收见 [COVER.md](COVER.md)。`--mode=...` 与 `--overview` 保留直接进入游戏的行为。

## 启动

2026-10-21 封面排版：中文名在左上、`CELL WAR` 在右上，采用米白 / 朱红 / 深蓝的新结构主义拼构立体字，中文名逆时针倾斜 3°、英文名顺时针倾斜 3°，横屏以 ±11px 幅度上下浮动。四个圆角台座共享前景地面透视，光圈位于台面面积中心；悬浮图标加大、加粗和圆角化，设置投影为红色、教学投影保持原色，保留点击扩散光环。角色预览内含角色预览和全身 / 心脏 / 双肺 / 小肠地图预览，保持只读。角色和解剖插画静止。实现与验收见 [COVER.md](COVER.md)。

在 Godot 项目管理器中导入本目录的 `project.godot`，等待资源导入完成后按 **F5**。首次会导入约 280 MiB 的运行素材，需要一些时间。

macOS / Linux 也可从仓库根目录执行：

```sh
./godot/run.sh
./godot/run.sh --editor
./godot/run.sh -- --mode=systemic
```

脚本优先使用 `GODOT_BIN`、PATH 中的 Godot、macOS Applications，最后使用本次放在仓库 `.tmp/godot-tools/` 的本地验证程序。该验证程序不随源代码交付。Windows 可直接使用 Godot 导入工程。

## 原版还原目标

玩法与地图继续保留原版素材与图层；首页按 2026-10-20 的新要求更新为新结构主义封面。当前为审核中的原生迁移版，尚未达到整套游戏完全一致。逐项证据和差异见 `PARITY.md`。

- 左键选择或拖框，右键下令或拖动平移，滚轮与触控板缩放。
- Shift 追加命令；侧栏可以删除队列项。多选移动采用经过地形检查的分散落点。
- 全景时 WASD 锁定；Q 放大后可用 WASD 平移，E 缩小；按住连续操作，镜头始终限制在整幅桌面画内。进攻和停止使用目标处的指令菜单。R 撤退、B 建设、H 返回首页、M 地图；F 定位当前选中目标，C 选择并定位下一枚己方细胞。
- Ctrl / Command + 1–3 保存编队，1–3 召回；空格暂停。存读档在菜单内操作。
- 菜单自动暂停并保留此前暂停状态；隔离解除后可恢复循环运输。
- 封面的“开始作战”按 2026-10-23 新要求打开存档选择；原循环防线入口、起始镜头和三细胞选择继续保留在选择战场中。暂停时指令排队，恢复后执行。
- 恢复原版首页、字体、建筑图集、检查站图像、顾问分层动画、七种透视模式和 0.75 秒切换。
- 修复已废弃心脏图层重复叠加；细胞、贴图和点击使用同一心脏形变。血管交叉按原版遮挡，隐藏细胞显示原版虚线标记。
- 删除额外选择光晕、命中数字、粒子和暗角的运行接入。细胞按源轮廓选择/碰撞，动画状态与源图集一致。
- 鼻腔、气管、双肺地形从当前原版绘制器离线转换，导航掩码仅用于通行检查。
- 已对照队友版补入小脑三话题、主动提醒、分句口型与状态表情、原版完整指引和手册；当前仍是纯 GDScript，未引入队友的 Windows Lua 规则宿主。对齐记录见 `teammate-alignment.json` 与 `PARITY.md`。
- 全身地图采用独立节点：底图、非血管连接衬底、器官、血管、游戏对象、指令、原图覆盖。打开 `scenes/world.tscn` 可逐层检查与显隐；界面仍使用独立 CanvasLayer。图层顺序与通行层身份分别保留，视觉交叉不建立道路连接。
- 按截图反馈修正完整衬底蒙版，恢复肺肝交界被裁掉的组织并清理膀胱等外沿的红色杂边。四档 LOD 共 41 块，保留原来的脊柱避让；属于用户要求的美术修复，未改变原 Lua、器官、血管或导航。
- 胃部/器官试验与沙盒恢复当前原版各自的底图分支；仅曲面底图使用 2 倍抗锯齿画布，器官覆盖图独立绘制。沙盒六步教程、胜负判定与提示已接入，完整经济回放仍待验收。

场景使用 Godot 的 Node2D、Camera2D、CanvasLayer 与 Control。每个逻辑图层有独立 Node2D；各层内批量绘制瓦片与细胞，避免给每个网格点创建节点。全身四类素材保持各自资源、裁边和透明度，不烘焙成一张合成图。

窗口采用 `canvas_items` 等比缩放：横屏基准为 1440×900，竖屏基准为 360×780，宽高比变化时扩展可视区域。字体、按钮、地图与输入坐标随画布同步缩放，竖屏保留原有窄屏布局。`ui_flow.gd` 覆盖窗口缩放、横竖切换以及缩放后的实际窗口坐标点击。

2026-10-21 用户将界面方向确认并细化为正上方俯视的纯平面 2D 指挥官桌面，人体地图平铺在桌面的图纸上。桌面采用鼠尾草绿、奶油色纸面与平面文具轮廓；图纸周围加入 GPT 生成的细胞、血管、组织等研究草图、测量括号与引线，并删除“人体作战图”和底部图层说明文字。最新细化将横屏图纸与实时人体一起左移、加宽右侧手机，左下的植物细胞式结构改成人体骨骼肌纤维，左侧补入放大镜和采样管，并为小脑对话保留空位。“人体防卫部”沿笔记本右下边线排印，不再使用悬浮标题卡。原图、选用版本和 GPT 内置图像生成提示词保留在根目录 `assets/image/command-desk-20261021/`，运行图由 `scripts/godot_tools/install_command_desk.py` 复制到 Godot 并登记哈希。早期立体设备台版本仅保留素材原稿，不接入运行。

`scenes/command_backdrop.tscn` 是不接收鼠标的桌面背景层。按用户最新澄清，人体、纸张、研究插图、尺子、文具与桌面手机共享同一套桌面坐标和镜头投影，拉近时相对位置始终不变。`scripts/desk_map_frame.gd` 将全身总览中的纸面范围固定到世界坐标，纸边随镜头自然移出屏幕，微观视图覆盖可见镜头区域；不再把人体单独放大在固定屏幕小窗中。手机壳与其原生对话控件同步随桌面移动，返回全局后完整恢复；资源栏、小脑、战斗操作和视野按钮仍为屏幕 HUD。

人体生存的新局先显示居中的全身图，继续记录恢复保存时的视角。全景锁定 WASD，放大后可平滑移动镜头，Q 拉近、E 拉远，缩放始终围绕当前视野中心；点击地图只用于选中与下令，不能设置镜头坐标。`scripts/camera_travel.gd` 驱动原生 Camera2D，暂停时仍平滑推进；独立人体图层不改变自身模型比例，不烘焙到桌面图里。眼睛左侧的纯图标按钮返回全局。左键点选细胞与框选保留，右键继续指挥。保留鼠标拖动用于框选，WASD 的移动速度随缩放换算为一致的屏幕速度；小地图点选定位保留。分块贴图预算、地图点击范围、框选和坐标标记均随可见纸面更新；保留关闭 GUI 位置取整以避免高倍率裁切偏移。交互回归入口为 `tests/inspection_camera.gd`、`tests/desk_camera.gd`、`tests/command_desk.gd`、`tests/ui_flow.gd` 与 `tests/life_ui.gd`；本项视觉细化仍待用户查看实际游戏效果。
