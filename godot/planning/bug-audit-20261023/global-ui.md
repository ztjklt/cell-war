# 全局细胞膜 UI · 美术与原生验证

日期：2026-10-24。用户授权将已认可的细胞膜风格推广到全游戏；在原工作区保留既有功能与素材，未提交或推送。

## 交付

- 共享 WarUISkin 改用奶油中心、珊瑚粉/淡紫膜边、深梅色字与轮廓。普通/主要/选中/悬停/按下/禁用状态均保留原生按钮、文本、回调和键盘焦点，原生进度值不烘焙。
- 覆盖主菜单四入口，战斗和全身HUD、存档、设置、战场选择、建设生产、资源运输、药品、器官协作、帮助、生活事件、图鉴搜索/分类/播放/动作下拉、顾问、手机气泡/回复、指令牌及坐标提示。动态重建的菜单也使用共享表面。
- 主菜单角色原画不变；菜单换为同尺寸膜卡片，图标漂浮、点击短反馈后单次导航。普通按钮复用原生悬停/按压Tween，弹窗淡入，手机消息保留原来的入场节奏；计时、暂停、经济、导航与存档规则不变。
- 小按钮、38px提示章、18px资源图标分别使用紧凑/微型规格，避免九宫格边界挤压。大面板只伸展中心和直边。原细胞素材直接复用，没有新增腿、脚或身体结构。
- macOS 独立下拉窗口同时开启 Window.transparent 与 Viewport.transparent_bg，保留素材外部的透明圆角。

## GPT 美术与来源

使用内置 image_gen；参考实际已认可的任务卡/HUD和原细胞画风。接受3张无字原稿：方形膜卡、长按钮、圆形拖动珠。中央透明或脏污的2张面板尝试只保留为拒绝稿，不进入运行目录。

- 原稿、参考、完整提示词、来源哈希与拒绝原因：`assets/image/global-ui-20261024/generation.json`、`prompts.json`（仓库根目录）。
- 离线裁切/缩放参数与运行图映射：同目录 `components.json`，制作脚本 `scripts/godot_tools/build_membrane_ui.gd`。
- 完整运行素材位于 `godot/assets/ui/membrane/`：panel、surface、badge、compact、micro、button、track、knob，共8张PNG。运行不依赖根目录工具、网络或生成服务。
- 原始资源稿与根目录 runtime 派生文件全部保留；Godot运行副本与派生源逐字节一致。

## 审查与验收边界

独立只读审查确认业务回调、disabled、动效释放和已确认角色/地图/玩法未受影响。审查发现的资源图标九宫格在18px竖屏超宽已改为micro并加入桌面及四尺寸断言；小顾问按钮、指令确认提示亦修正角尺寸。

macOS 独立 PopupMenu 的项目选择不能通过本机 Viewport.push_input 合成路径可靠驱动：失败驱动保存在 popup-driver-limitation.log，不能计为已通过。自动化只验证打开/绘制/透明与取消；另以 cua 系统鼠标实际打开正常游戏中的下拉菜单并点选“角色立绘”，观察到标题/角色/播放按钮状态同步变化，确认用户操作路径正常。

部分图鉴独立测试在退出时打印 ObjectDB 清理警告，相关断言均通过；未据此声称引擎退出无警告。既有 life_ui.gd 仍采用“整段动画完成才允许选项”的旧规格，本轮未改变其与现行已显示选项可点的差异；使用当前 life_interaction.gd 和真实手机点击验证。

这是桌面Godot原生窗口验收，不等于手机真机、云存档、全量旧版画面/玩法一致性认证。
