二、宿主API契约
service = WarAdenovirusAttack.new()
service.bind_world(damage_callback, geometry_callback, knockback_callback)
三个回调都必须绑定；缺失时禁止起手/推进活动攻击，绝不降级直接扣hp。

geometry(from:Vector2,to:Vector2,lane:int,source:Dictionary,
         target:Dictionary,purpose:String) -> bool
purpose为cast/impact/target/push；cast和impact时target为空。
只接受严格bool true。适配器必须检查真实地形孔洞、墙、门、平面身份和
真实可达关系，同点查询也必须检查。不得以距离或画面重叠代替拓扑。
target阶段应允许攻击目的关口本身的合法近侧表面，但不得忽略其后方遮挡。
有多个通道口的关口须由宿主提供当前lane的真实目标点；每步每id唯一。
如使用几何代理，damage回调必须映射到真实actor并同步返回hp/存活状态。
service自身先筛选同lane，再检查锁定点到目标的几何；不执行通道转换。
冲击发生时先确定全部目标和遮挡，再调用伤害；本次击破的门仍遮挡本次冲击。

damage(source:Dictionary,target:Dictionary,amount:float,info:Dictionary) -> void
source/target为宿主提供的实时actor，info包含cause=adenovirus_slam、castId、
point、lane、impactAt。宿主应调用已有伤害系统保留护甲/科技/死亡/关口逻辑。
建议使用独立cause，避免 WarCombat 的普通攻击自动击退与本服务击退叠加。

knockback(source:Dictionary,target:Dictionary,displacement:Vector2,
          info:Dictionary) -> void
只对伤害后存活普通unit调用，building不击退。服务按0.05步长检查几何并
裁短至最多0.35；宿主仍须应用队形/占位与血小板抗推修正，并保持原lane。
不会通过改变画面偏移强行写入新导航位置。

begin(source,aim:Vector2,sequence:int) -> castId，失败返回0。
actor必须含id/kind/category/faction/hp/x/y/vesselLane，orderToken默认0。
sequence由宿主对每个actor递增；重复、越界、冷却中或无效调用不消耗序号。
IDs在同一会话/存档内不可重用。最多4096个来源记录，满额安全拒绝新来源。
未改公共构造器；当前正式游戏不能直接spawn未注册的adenovirus。

advance_simulation(delta,entities) 或 advance(real_delta,entities,paused,time_scale)
二者选一，不得重复推进。entities包含施法者和当前单位/建筑字典，每id唯一。
碰到死亡、缺失、换orderToken、换lane、换阵营或本体位移，取消当前攻击。
hitTime高于起手记录也会取消，作为未显式通知受击时的后备保护。
渲染不得调用推进、扣血或击退；警告圆的位置、lane、半径与剩余时间来自
presentation(id).warning，锁定目标可以在820ms前离开该区域躲避。

notify_hit(actor,toward_attacker:Vector2) 接真实受击事件；输入是宿主投影后的
局部“受击者指向攻击者”向量。x正选hit-right，负选hit-left；垂直沿用前侧。
一个受击动作中再次受击不切换方向、不倒回帧；起手前被打断不产生冲击。
damage回调可直接notify_hit/notify_death打断另一个蓄力者；时间推进、begin、
bind_world、snapshot/restore仍禁止重入。几何回调应只读世界状态。
notify_death(actor) 要求hp<=0，重复通知不重播死亡。
cancel(id,reason)供外部显式取消（冲击回调中不得重入cancel）。

animation = WarAdenovirusAnimation.new()
animation.sample(service.presentation(id),moving) 返回clip名、frame、原图path、
rect、anchor、rotation、mirror、scale、hidden。此采样是纯显示，没有动画事件
驱动伤害。宿主world_view仍需适配该返回结构，并提供独立死亡保留时间。

三、存档契约
snapshot()输出纯JSON数据；restore(dict)事务性校验后替换，不执行事件/伤害。
保存clock、nextCastId、来源序号、冷却、受击侧/开始时刻、死亡时刻和活动cast。
规则必须与当前定义一致；未知字段、重复castId、无效时间/坐标/整数、过期仍
未结算的冲击及提前标记resolved的冲击均拒绝。拒绝后服务原状态不变。
在冲击/几何回调中snapshot返回空字典，restore返回false，避免半次扣血存档。
宿主须在同一个固定步边界原子保存世界actor与服务，不能混用不同时刻快照。
载入前冲击会在剩余时间到达后结算一次；载入已结算冲击不会重放。
回调不序列化，新服务恢复后必须重新bind_world；没有绑定时不推进活动cast。
本分工未接入WarSave。正式存档schema登记、公共验证和恢复顺序仍由主集成完成。
