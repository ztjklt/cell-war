细胞战争：感染区域、病原据点与关口扩张实施计划
日期：2026-10-20
状态：首批12个器官候选范围、56个合法小地板落点、GPT感染地表贴图及Godot交互预览已实现；刷怪、建巢、联合占领净化与手脚组织域尚待后续实施。验收见 preview-delivery.txt。

一、工作范围
在现有 Godot 纯 GDScript 工程实施。沿用既有人体、器官、血管和紫色关口，保留独立图层及通行平面身份。当前用户授权新增感染/受伤区域与扩张玩法，早期还原阶段的“不加覆盖层”约束不阻止这次明确要求的战斗区域层。
显示分为两层：潜在区域的战术边界/编号仅在辅助战斗视野显示；正在发生感染且持续刷怪的区域，在正常游戏画面中也显示 GPT 制作的感染地表贴图。巢穴、要塞、受伤组织、攻击特效等实际美术使用原素材或经审阅后 GPT 生成的贴图。

二、阶段与交付
1. 素材与地图审计（本轮已完成）
   七个病原体包有技能动作；审计详见 asset-audit.json。
   当前12个器官共30个已登记关口；手脚尚无独立器官组织导航域。
   现有 Godot scenarios.gd 已有寻找、攻击、突破关口的病原体行为，可在其上扩展，不另造一套穿墙移动。

2. 感染/受伤区域与布局（下一实施批次）
   先覆盖12个器官，每器官按实际可通行空间选择1至数个候选区；手脚单独补组织域、边界和血管接驳契约，再接入同一系统。
   两级范围：器官/肢体内预先规划较大的潜在感染范围；单次感染事件只在其中选择一小块实际感染地板。两者分别保存ID和边界，小地板对应实际刷怪和联合净化占领。
   潜在大范围排除关口保护带。每次选点还要独立检查小地板完整轮廓、实际出生点、初始建设位与相关所有关口的安全距离，不能只检查地板中心或只避开一个目标关口。
   小地板完整落在合法组织内，避开血管腔、孔洞、障碍、既有建筑，并与目标关口间保留实际可达的攻防通路。地板大小和关口安全距离集中配置，结合真实行军与交战空间校准。
   一次感染事件选定小地板后，连续刷怪和初期建设围绕该落点展开；新感染事件可选择大范围内另一合法位置。候选不合法时延后重试，禁止退化为贴关口出生或越界落地。
   区域记录：稳定ID、所属器官/肢体、事件类型（感染/损伤）、边界、可用出生位、可用建设位、目标关口、真实路线、最小推进距离、启用状态、净化进度、红细胞/白细胞数量要求、占领时长、刷怪源状态、感染地表贴图。
   区域为潜在事件位置，不等于开局全部激活。受伤区和病原区采用不同事件类型；具体伤害、触发条件和病原投放表仍待逐项确定。
   先检查单位完整碰撞轮廓、建筑完整占地、器官边界、孔洞、现有单位、资源点及运输线。出生点不得覆盖关口或堵死唯一出口。
   用实际合法路径衡量出生点到关口的推进距离，并检查沿途可供双方交战和绕行的净空。距离以相关兵种射程和行军时间共同校准；不将直线距离当作通路证明。
   准备区域编号与关口、路线配对图；未通过路径和原生画面复查的落点保持候选状态。
   区域的战术边界、编号和调试落点只在现有“战斗视野/辅助视野”开启时显示；纯净视野隐藏这些战术标记。活动感染地表在正常游戏画面中也可见，仍服从原地图层显隐与组织遮挡。切换不推进战斗、不重生敌人、不影响选择。

3. 右肺先行闭环
   从潜在大范围选定合法小地板 -> 感染地表逐渐显现 -> 病原体从地板上逐渐出现 -> 前往合法建设位 -> 经建设时间形成小巢穴 -> 存活据点支持增殖 -> 在可达范围选择扩张位置 -> 建立病毒要塞 -> 组织攻击紫色关口 -> 突破后沿已登记血管通路前往另一器官 -> 建立新的落脚据点。
   病原体逐渐出现属于出生表现阶段，缺少独立出生动作时向用户报备；不默认把攻击动画当成出生动画。出场阶段的可攻击性另作明确规则，贴图渐显不能重复创建实体。
   建设是模拟状态，存在未完工和被打断；禁止一出生就瞬间生成完整要塞。
   战略主目标为关口。附近交战是清障、自卫和保护建设，不允许自动寻敌使整队长期偏离扩散目标。
   扩张必须由存活单位实际到达；隔离、失守关口与合法平面关系继续参与通行，不跨器官直接刷据点。
   初代巢穴/扩张要塞/扩散前线作为数据角色区分；先用两个建筑外形，不为每种角色立即新增一套美术。
   繁殖间隔、建设时长、资源来源和消耗、最大据点数与活跃单位数集中配置并标为联调值。避免无限增殖；沿用现有补给守恒思路。
   与当前循环防线分开登记场景状态和胜负条件，接入前明确重置边界，不叠加两套繁殖器。
   用户最新确认的清除闭环：区域发生感染 -> 感染地表出现并持续产生病原体 -> 足够数量的存活红细胞与白细胞实际同时驻留该区 -> 达到占领时长 -> 区域完成净化、关闭对应刷怪源、感染贴图消退并露出原地面。
   仅击杀一批敌人不等于完成区域净化；占领是独立的区域目标。人数和时长集中配置，尚未确定具体数值，不以地图其他位置的单位计数。
   净化进度由模拟时间推进，暂停时冻结，存读档保留。细胞离区、敌军争夺时的进度保留/暂停/回退规则尚待确定，不在本规划中暗定；据点与区域刷怪源的绑定应统一，避免完成净化后被旧繁殖计时器继续刷怪。
   既有敌军、其他感染区与已扩散器官独立记录；本区净化不会自动等同全身胜利。占领特效另做素材规格和提示词，达到用户审阅要求后制作。

4. 多病原与多器官
   首批复用流感、疱疹、腺病毒、幽门螺杆菌、肺炎链球菌的原图及已有技能，建立单独角色ID、动作表和碰撞尺寸。
   幽门鞭毛和疱疹既有接触/击退规则保留；其他效果先写成角色方案再逐项联调，不把现有技能命名当作已确认数值。
   攻击图不冒充移动或死亡图。缺动作上报用户，由另一对话补图；可继续验证逻辑，但视觉验收保持待完成。
   蛔虫与猪带绦虫作为后续病原体批次：现图有道具或背景问题，待独立透明角色图补齐再正式接入。
   先从右肺扩到可达邻接器官，再覆盖所有器官和左右手脚；在地图上存在真实通路才允许扩散。

5. 验收
   地理：大范围包含多处合法小地板落点；每块小地板完整边缘及出生/建设占地处于关口保护带外；到目标关口有可达路径和足够推进空间；视觉交叉不连通。使用多种随机种子与边缘候选验证，失败候选不得绕过校验。
   行为：建设可打断、据点可摧毁、扩张有成本和上限、关口优先、不隔空建设、关门确实阻断扩散。
   显示：辅助视野可见区域战术边界；纯净视野隐藏战术标记但仍能看见活动感染地表；净化后感染贴图消退、原地面恢复；实际单位和建筑仍按原游戏显示规则绘制。
   占领：实际在区内的存活红细胞和白细胞共同满足数量条件才推进；达到时长仅关闭本区关联刷怪源；后续模拟、读档与旧繁殖计时器不意外重启该源。
   状态：暂停不推进；存读档保留感染区、净化进度、刷怪源状态、建设进度、据点、扩散目标和关口状态；重试不伤及无关器官单位。
   执行 Godot 导入/解析、定向逻辑测试和现有相关回归，再用原生窗口检查区域、图像锚点、命中、遮挡与行军路线。
   每批对照证据报告已实现、待验收和素材阻塞。规划文件本身不代表运行验收。

三、美术执行顺序
先由用户审阅 art-prompts.txt 中提示词；批准后使用 GPT 生图。
新增感染地表为优先素材：在现有组织地面上叠加独立透明贴图，不改原人体底图；按实际区域遮罩限制在器官/肢体组织内。随后制作要塞样张、小巢穴及建设中、受损、废墟派生图；派生图继续遵循用户审阅范围。
最终图为独立透明PNG，记录提示词、参考、来源与校验；复制到 Godot 工程内部正式素材目录，运行不依赖外部路径。
碰撞形状可由代码定义；正式建筑画面必须使用经审阅的美术贴图。
