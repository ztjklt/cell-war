# 局内 UI 组件与环形指令

2026-10-20 用户确认 V5 奶油米色 / 可可棕方向，要求实际组件与点击式环形指挥；之后用户要求实际 UI 改为浅立体多面体，包含切面图标和动态效果；最新指示取代此前纯平面限制。封面不在本轮范围。

## 查看实际效果

```sh
./godot/run.sh res://scenes/ui_components.tscn
./godot/run.sh -- --mode=lung_skirmish
```

组件页的按钮、状态条、数字、中文字体和环形选项均使用真实 Godot Control；按钮可点击。组件页不是游戏底部的布局。

## 游戏操作

- 点击或左键拖框选中细胞；再点击目标位置，弹出环形菜单；选择指令后确认。右键点击同样打开菜单，右键拖动仍平移地图。
- 点外侧、中心 × 或按 Esc 取消，保留选中的细胞，不下达命令。菜单不暂停时间；原本暂停时确认的指令继续遵循原队列规则。
- 菜单避让窗口边缘；命令始终使用初次点击的地图坐标。Shift 或“追加命令”保留追加队列行为。
- 作战细胞显示移动、进攻、驻守、撤退、停止。目标是敌人时，进攻变为集中攻击该目标。
- 红细胞在资源处可采集，在未完工 / 受损友方建筑处可协助建造 / 维修；其他位置可进入建造子菜单。战役不提供建设。
- 建造子菜单包含原有 14 种建筑，分页选择；显示花费和科技 / 资源禁用状态。点击配方后按原来的落点、组织地形、占用和资源规则建造。
- 选中建筑后再次点击它，或右键点击集结位置，可打开生产管理 / 设置集结点。原有训练、研究、编队和选择单位功能在 ≡ 菜单；A / S / R / B 快捷键保留。

底部整排常驻指令按钮已移除，仅保留小型信息卡、地图工具和战役调援。人体图层、细胞素材、通行规则与战斗规则没有随样稿重新绘制。

## 可复用实现

- `scripts/ui_skin.gd`：颜色、字体与主题工厂。`facet_surface.gd` 提供六边形 / 削角切面、厚度和状态反馈。
- `ui/cell_theme.tres`：可直接指定给 Control 的颜色和字体主题资源；动态切面还需配合上述组件。
- `scripts/command_button.gd`：图标 + 文字的真实按钮，普通、主操作、次操作、禁用和焦点状态。
- `scripts/command_icon.gd`：随分辨率缩放的实心多面体图标，正面 / 侧面 / 浅色切面分别绘制。
- `scripts/smooth_icon.gd`：指令 / 资源图标的局部超采样（双倍宽高、四个采样点），兼容当前 Compatibility 渲染器；仅图标状态变化时更新小型透明缓冲，不对整幅战场做超采样。
- `scripts/command_wheel.gd`：围绕目标展开的上下文菜单、取消、避边和建造分页；0.22 秒逐项展开、0.018 秒错峰，悬停抬起、按下反馈、选中徽章向原目标收拢、其他选项同步退场、落点勾选与已下达 / 已排队确认。
- `scenes/ui_components.tscn`：独立组件试用页。

标题使用站酷快乐体，按钮与数值使用站酷庆科黄油体，小字说明保留 MiSans；中文缺字回退至随项目打包的 MiSans。新增字体附带各自 OFL 授权文本。

## 验证

```sh
./godot/run.sh --headless --editor --import --quit
./godot/run.sh --headless --script res://tests/radial_commands.gd
./godot/run.sh --headless --script res://tests/ui_flow.gd
./godot/run.sh --headless --script res://tests/run_tests.gd
```

环形测试注入真实窗口坐标点击，并覆盖未确认不下令、取消不穿透、原目标坐标、原经济系统实际建造、采集、科技限制、横竖屏与四角避边。窗口验收不等同于手机真机验收。

执行验收：`./godot/run.sh --script res://tests/radial_execution.gd` 使用真实地图点击选择 / 打开环形菜单 / 点击命令，再运行实际 `game.update()`。82 项检查覆盖暂停等待、恢复后到达目标、行进中停止、进攻推进、攻击目标实际扣血、驻守、撤退至已占用据点旁、采集减少资源并增加携带量、建设扣费并完成、协助已有工程、维修扣费回血和建筑集结点。全身地图另测窄路友军阻挡：先通过 UI 移走前方细胞，再通过 UI 指挥红细胞通过，不跳过原有碰撞或寻路规则。测试隔离场景采用项目内 `cell_test`，采集另设固定资源样本；器官移动使用实际 `fullbody` 地形。执行证据写入 `test-output/radial-execution.json`。

上方资源名称固定为“氧气量”“葡萄糖量”，不添加器官前缀。资源数值变化采用 0.22 秒过渡；左侧信息卡使用切面头像徽章、轻微呼吸与选中反馈。

新增原生组件：`selection_emblem.gd` 使用实际细胞图集作切面头像徽章；`order_pulse.gd` 在徽章收拢后提供勾选与状态确认，不再播放独立外扩形状。`tests/facet_motion_capture.gd` 记录实际展开、悬停、按下和确认操作，预览输出 `test-output/ui-faceted-motion.gif`。

最新打磨：所有六边形与削角框保留切面厚度，转角使用相切圆弧；点击区域与轮廓一致。按压采用阻尼回弹，0.33 秒整体确认过渡期间锁住重复点击，不会重复下令。组件页的环形示例也可实际播放整段确认动画。局部实录：`test-output/ui-rounded-press.gif`。

清晰度与点击修正：移除指令按钮获得焦点后的内圈描边；键盘焦点继续使用已有抬起 / 色彩反馈，按压回弹与整体确认动画保留。指令图标由 30 调为 34 逻辑像素，轮廓线由 0.75 调为 0.9；指令和资源图标统一双倍宽高绘制后线性缩回，合并四个采样点，不添加锐化光晕。当前 Compatibility 渲染器不支持 2D MSAA，因此没有设置无效的全局 MSAA 开关。

原生窗口验证：`./godot/run.sh --script res://tests/icon_quality.gd`，20/20（图标实际输出非空、采样尺寸、键盘焦点保留、焦点前后像素一致）；环形指令 84/84，横竖屏 UI 流程通过。原尺寸清晰度截图：`test-output/ui-icon-clarity.png`。此前 GIF 为旧录屏，不代表此次清晰度修正。
