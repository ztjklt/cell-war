# 内部隔断与器官特色：只读复核

本记录审查本轮 11 器官几何，不修改既定外形、墙、血管、膜口、保留腔道或美术资产。

32 个新增隔断共用宽开口有机弧形组织湾。数量、尺度、放置范围有差别，但它们仍然使用同一形状语言，无法仅靠墙形区分全部器官。碰撞和连接验证通过，不代表器官特色已经验收。应通过器官本身的组织分区、宽色带和温和的平面纹理区别，避免让所有图成为同款圆房间。

| 器官 | 新增区域 | 与原 biologicalDesign 的关系 | 固定几何下的美术约束 |
| --- | ---: | --- | --- |
| 肝 | 3 | 保留宽叶区及旧组织岛；低密度，不是蜂窝小房间 | 暖红棕、粉肉色的宽肝叶色块与少量大尺度小叶纹，不铺密集六边形。弧形湾应看作组织叶区的局部隔断。 |
| 心 | 3 | 保持开放心肌地面、大血管和冠脉接口；3 湾不代表解剖心腔 | 通过宽心肌方向纹和温和红粉色带体现收缩组织，不能画成 3 个真实心腔或血液池。 |
| 左右肺 | 各 3 | 原气道保留；宽肺组织区域仍连接，避免肺泡地毯 | 两肺需保持各自原轮廓和气道，使用柔软粉色肺叶材质、稀疏小尺度气囊痕迹。不能把支气管画为血管、不能用密孔填满地面。 |
| 脑 | 4 | 仍为少量宽支撑组织湾，无密迷宫；弧形隔断存在同款房间风险 | 保留左右组织差别，用圆润宽脑回色带和轻微神经纤维地面纹体现特色。不能画成人造圆房、洞穴或密神经迷宫。 |
| 左右肾 | 各 2 | 保留单独肾盂及宽皮质组织地面；膜口不镜像移动 | 红粉皮质、暖奶黄髓质的宽弧分区及少量径向条带。肾盂边界必须独立，不能把尿腔画成普通战斗房间。 |
| 胰 | 2 | 保留分泌管与宽小叶区；稀疏隔断没有切断组织通路 | 奶黄、浅粉的宽小叶质地；保持横向长条形节奏。避免把局部小湾强化为两个大型圆腔。 |
| 膀胱 | 3 | 原尿腔与细胞壁组织层分离；新增弧形湾仅位于可走壁组织 | 温和肉粉/浅黄的黏膜色差和轻微壁褶，尿液核心保留清楚边界。血管不能凹入尿腔，也不能把尿腔铺成可走地面。 |
| 小肠 | 3 | 顺已有组织袢安排开口小湾，食物流管独立 | 用短、软、方向一致的黏膜褶皱和暖粉/浅黄色层次表示肠壁。避免凸起绒毛堆、岩石地形或横穿保留腔道的捷径。 |
| 大肠 | 4 | 大弧形外壁、食物流管、中央空洞和原多组件/膜口全部固定 | 用较宽、间隔较大的结肠袋/壁纹，与小肠细短纹区别；中央洞不得补地，隔断不得变成闭合腔室。 |

当前几何没有器官特色导致的实际寻路冲突；最需要美术警惕的是心/脑/肝的同款弧形房间感，以及肾/胰的圆湾可能盖过天然的长条或径向特征。以上要求均可以在保持墙/开口/碰撞不变的前提下处理。若最终仍无法区分，应单独讨论局部隔断形态，而不能让生成模型自行移动墙。

色彩按最新用户要求：胃可以保留少量绿色，其余器官以红、粉、黄为主，纹理保持平面、温和、可爱；器官特色优先于把所有图套用胃的同一套房间纹理。
