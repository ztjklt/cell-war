## 真实画面的主要判断

器官贴图确实进入了真实游戏，地面有了手绘组织、低对比纹理和不同器官的色差。但目前整套 0.15 画面尚未形成统一完成度：精细的器官地面旁边仍是粗矢量人体色块和很宽的纯色世界血管，内部精确血管/墙又是简单矢量带。真实画面比单独的器官素材显得更拼接。

这次观察到的主要不足集中在以下五项：

1. **世界层与器官层质感差异大。** 心脏左侧、双肾门部、大肠右侧的蓝色主干非常宽、颜色实、细节少；器官外的红紫肌肉/结缔组织也是大色块。新器官是柔和绘制纹理，连接处仍像贴上去的窄管带或蓝色色舌。所见没有大片黑图、明显白色贴图缝，但“资源能贴上”不能等于“各层已自然融合”。
2. **器官外侧仍有绿色粗填色，整套去绿色尚未完成。** 06 右肾窗口中，门部蓝色大主干后方有明显竖直浅绿色粗色带；它位于新肾贴图之外，仍属于玩家看到的 0.15 地形。因此“受限器官 PNG 没有绿底”不能泛化为“整个真实画面没有绿色”。胃、肝的保留绿色是明确例外，HUD 和细胞标记不计为地形；其余器官外侧的残留绿块仍是全视图待处理问题。根因层次须由运行代码定位，本报告不猜其所属组织。
3. **单位在 0.15 的真实窗口偏小。** 中央选中细胞主要靠绿色选择圈/生命短线找得到，单靠单位本体不能轻松认兵种。新地面整体平坦，未出现真实立体肉块挡路的感觉；不过小肠较密的斜笔触、胃的颗粒和色块会让很小的单位更难识别。截图只呈现少数静止单位，不能证明密集战斗的可读性通过。
4. **墙、可走组织与保留腔道的视觉语义尚不够清楚。** 新版 C 弧只有一套精确前景，开口没有被 GPT 硬描边再封上；但它们多为细淡棕线圈，房间重复感较强，像绘在地面上的装饰线。浅黄食物/尿液/气道区域从颜色上独立，却也容易被看作可走的宽道路；只看一帧不能知道哪些色块可走、哪些墙不可越过。视觉辨识仍需提升，不能把几何边界存在就当玩家必然看得懂。
5. **HUD 大量遮住地形。** 上方资源栏、右上目标框、横贯画面的试验提示条、下方命令栏覆盖了多个器官边缘、墙端和出口。蛋白质数值在当前资源栏还换行显示。真实可见战场比素材画布少得多；这些是当前窗口的既有 UI 表现，不归因于本轮配色素材的新故障。
