## 截图接口失败原因的证据范围

历史 91 次内置截图失败；新增六个阶段重试也全部 false / 0×0。独立 PNG 写入对照成功，窗口有焦点、未最小化、引擎初始化且未丢失设备，完整贴图已加载。只读检查的内置函数路径是 requestScreenShot → frame → WaitImageScreenShot(...,1000)。六次调用各耗时约整秒，与等待失败相符。缺少渲染器回调日志，不能断言具体 Metal、线程或 framebuffer 缺陷。

系统窗口截图成功，证明实际窗口能显示并能被系统截取；此方法绕开了失败的引擎图像回读路径。
