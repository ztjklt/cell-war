# 胃部 GPT 血管材质试样

本批已生成并接入胃部试样：共享动脉、静脉和局部循环材质，另生成固定胃壁入口的分叉原料。原生 Metal 窗口已取得本次素材的供给、组织入口和回流三个 zoom=0.15 视口。全身其余血管及正式战役还未使用这一批材质。

## 制作与坐标

- 模型：GPT 内置生图。原始输出、提示词与来源见 `generation.json` 及三个 `*-prompt.txt`；原料保留在项目资源目录。
- 原图坐标为 1024×1536。运行时 sourceBox 固定为 `[464,448,644,628]`，两个最终 PNG 都是 2160×2160。
- 原图点 `(sx,sy)` 对应世界点 `(sx*2,sy*2+512)`。游戏每世界单位是 `32*zoom` 逻辑像素；0.15 时每原图像素对应 9.6 个逻辑像素，DPR 不改变这条关系。
- GPT 只提供材质；定稿曲线、可见片段、碰撞、胃轮廓、食物通路和五个细胞组织入口决定最终形状。隐藏的主干不为了视觉连续而画到肝脏表面。
- 编译器在制作阶段用共享三角采样并裁剪原料；运行时只绘制两个烘焙图像。被遮挡的外部端点用小范围渐隐承接深度。原版胃地面只在获准血管遮罩内替换，食物通路保持原像素。

## 运行入口与维护

`scripts/war/VascularMaterialArt.lua` 管理世界及 UI 两个 NanoVG context 的资源。由已有 `GastricArt.prepare/release` 配对调用；`ReferenceArt.draw` 先绘制胃外血管，再绘制器官。`GastricArt` 在原胃图和候选胃图中选一张，避免叠画两套地面。

两张候选图必须同时解码成 2160×2160 才接管。资源缺失或引擎返回 16×16 占位图时继续用原胃图。每 context 增加两个图像，不在 draw 中加载资源。透明度沿已有 0.085→0.15 的曲线过渡。

如修改原料、定稿路线或允许遮罩，先运行 `scripts/qa/build_vascular_material_pilot.py`；再运行 `scripts/qa/check_vascular_material_pilot.py --help` 选择检查模式，最后运行 `scripts/qa/publish_vascular_material_pilot.py`。发布器只接受与当前素材及渲染代码 SHA 对应的证据。不要把变更后的素材沿用旧截图。

本批没有增加存档字段、迁移旧版人体、改变寻路数据或替换正式战役素材。用于截图的 main.lua 临时启动钩子已按原始 SHA 恢复；可选验收驱动单独保留在 `scripts/qa/VascularMaterialNativeViews.lua`，不会自动运行。
