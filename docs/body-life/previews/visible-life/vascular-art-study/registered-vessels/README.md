## 文件

- `full-body.png`：完整器官前景后的主图试贴，1024×1536。
- `vessel-overlay.png`：透明主图血管层，1440×2376；锚点 `[333,250]`，源范围360×594，4倍栅格。
- `cutaway-overlay.png`：同一坐标的壁内显示层，随现有填色透明度显露；食物／原支气管／膀胱前景约束继续生效。
- `cutaway-torso.png`：壁层定位审查图，不是最终0.15器官内部战场素材。
- `geometry.json`：冻结路径与精细显示遮罩；`overviewPaintPath` 与 `paintPath` 表示两个显示层，不能据此修改导航或创建跨系统连接。
- `generation.json`：GPT材质、源图、定稿与全部输出SHA，静态三角只在制作时烘焙。
- `checks.json`：像素、坐标、管径、保护区与离线证据核对。

主图 54 个连续可见区域中，23 个远离固定接口的短碎段降低至 10% 显示；所有命名接口的接近段保留。主图新绘画共改变 2514 个源像素，均在允许的血管范围内。

浏览器复核覆盖 1440×900、1024×768、844×390、430×932、360×780，均无横向溢出。实测 0.15 填色 100%、0.11538 填色约45%、0.08876 填色约1%，缩放和原图切换不重置回放时间。检查期间浏览器 DPR 为1；DPR2/3仅有离线坐标证据。截图与页面、素材哈希记录在上一级 `registered-vessels-browser-evidence.json`，临时视口已恢复。12个单位样本及回放证明当前绘制尺寸和记录位置，不能证明新的膀胱寻路或原生战役表现。

## 重建

在项目根目录执行：

```
python3 scripts/qa/build_registered_vascular_art.py
python3 scripts/qa/check_registered_vascular_art.py
python3 scripts/qa/publish_registered_vascular_art.py
```

制作器先导入本机兼容的 Numpy / Pillow / CFFI，再使用 `/tmp/reference-map-tools` 的 CairoSVG 和 `/tmp/passage-tools314` 的 Shapely / Lupa。它们是当前工作机依赖，不是生产游戏依赖。CairoSVG亮度mask不能用黑色作减法；器官前景必须用几何差集的clipPath。替换环境时安装对应Python版本的依赖，禁止混用cp313与cp314的二进制包。

网页按每个绘制项使用 `floor(smoothstep((zoom-.085)/.065)*255)/255` 的实际填色透明度，0.15完全填色。细胞图形来自实际Render.draw；0.14以下沿用固定逻辑像素远景点，0.14及以上使用真实单位尺寸。位置只采样记录的Lua轨迹，不做直线插值或虚构血管移动。

发布器只写已有静态预览目录，不开新服务器、不启动已停止的原生预览。原生预览 reload22 已停止。原生GPU接缝、过滤、帧时、真实战役单位与全部局部战场美术尚未确认。
