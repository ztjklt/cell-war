# 卡顿优化与验证

本轮保留地图尺寸、逻辑像素/DPR、迷雾规则和血管通行规则，针对 Lua 热点减少重复工作。

- 已探索迷雾与当前可见迷雾分别缓存；静止视野复用原有轮廓，直接揭示区域也会使对应缓存失效。
- 鼻腔黏膜细节先按视野剔除，再缓存静态组织/血管判断。
- 血管导航使用 32 格空间索引，绘制仍保留原来的 128 格索引；膜口索引在位置验证结束后建立，覆盖跨桶半径。
- 每次模拟给寻路约 3 毫秒 CPU 时间片；A* 与路径简化均可继续，任务之间轮转。单次扩展/简化片段和 GC 仍可能超过预算，因此不是硬实时上限。
- 固定步长追赶约 6 毫秒后留到下一帧，降低堆积更新造成的长停顿；重负载下模拟可能暂时落后。
- 主菜单覆盖世界时跳过隐藏地图绘制。

Lua 5.4、1920×1080 逻辑尺寸、种子 73、空 NanoVG 绑定的对比：

| 情景 | 优化前 | 优化后 |
|---|---:|---:|
| 鼻腔近景 + 小地图，30 帧均值 | 3.83 ms | 2.36 ms |
| 鼻腔 0.24 缩放 + 小地图，30 帧均值 | 4.94 ms | 2.68 ms |
| 鼻腔静止视野刷新 + 绘制，10 次均值 | 14.30 ms | 2.23 ms |
| 沙盒模拟，100 步均值 | 20.48 ms | 4.26 ms |

这些是 Lua CPU 计算开销，不能换算成原生帧率。实测沙盒 300 步仍偶发约 20–30 毫秒更新，主要来自首次生成新区域资源；本轮缩小了血管查询范围，但区块资源仍同步生成。原生 GPU、设备发热、图片解码与 UI 布局开销未验证。

原有 71 项回归通过（解剖、鼻腔、血管、缩放、存档、移动等），新增 6 项缓存与寻路检查通过。Lua 语法检查通过，LSP 未新增 ERROR；项目原有 16 项 ERROR 保留。
