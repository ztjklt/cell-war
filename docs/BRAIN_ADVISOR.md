# 脑细胞联络员「小脑」

小脑作为独立分层人物放在左上角，常规尺寸 176×176，不含底框、边框或底板，身后直接显示人体地图。鼻腔区域状态、补给信息、工具栏及事件目标移到右上角；窄屏区域状态改成三行，以保留完整状态名称。

点击小脑后选择「人体情况」「守卫建议」「援军补给」。问题与回复都以独立的深黑短条展示，移除姓名、播报标题、状态字样、整体底框和尖角。长文本按标点与行宽拆分，通常一条一行，正文 11pt；单条从左侧移动 24px，约 0.32 秒滑入并淡显，间隔约 1.65–2.45 秒，最多同时保留三条。短屏自动减少同时显示的条数。旧条淡出，新条向上补位；自动播报全部读完后依次淡出，长播报会延长计时，避免尾段丢失。

话题操作只在手动打开时显示；「»」跳过余下播放。关闭按钮、再次点击小脑或 Esc 收起对话，地图持续运行并保留战术暂停和选择。其他弹窗临时隐藏短条并停止播放计时，关闭后继续。最近六条问答保留在会话状态中，新游戏或读档清空。

回复读取当前鼻腔战役的区域控制、敌军进入情况、入侵波次、稳定计时和补给冷却。沙盒旧存档则介绍胞群、周期与葡萄糖。不伪造未开放器官的感染信息。当前是游戏状态驱动的预设对话，不调用在线语言模型。

入场问候、病毒新波次、后鼻屏障告急、完全夺回区域及全域净化触发自动短条播报。每条显示期间循环口型，停顿与播放结束时静止；待机悬浮和鼠标视线持续更新。同一事件不会每帧重复提示，暂停或弹窗时保留待观察变化。

实现：`scripts/war/BrainAdvisor.lua` 负责只读战况解读和提示，`scripts/war/BrainUI.lua` 负责独立人物、短条播放与对话；由既有 HUD 调用。

当前角色以用户最新上传的 390×380 参考图为目标，使用素材包部件重新组装。原始 `brain_cell_production_pack_v1.zip` 完整保留于 `assets/image/brain-advisor/production-v1/`，未修改原文件；参考图保持为 `reference-portrait.png`，仅作对照与贴图缺失时的静态回退。

## 分层动画与补绘素材

素材审计见 `docs/BRAIN_ASSET_AUDIT.md`。包里的两个身体都是七分枝，独立触手偏细长，镜框为近正面视角，不能直接拼成参考图的六分枝与不对称透视。因此用内置 imagegen 补绘两张透明纹理：`rig-v2/anatomy.png`（无脸、无平板的六分枝底图）与 `rig-v2/glasses.png`（匹配参考图透视的空镜框）。提示词与生成来源见 `rig-v2/PROMPTS.md`。

继续复用包里的左瞳孔、闭眼、五种嘴型、平板底层、屏幕、轮廓和状态提示。右瞳源图被截断，左右眼复用完整左瞳，再各自缩放；说话 O 嘴与平板的源裁切已修正，避开邻近图案残片。静止时隐藏嘴，更接近原图。

`BrainRigData.lua` 定义源图窗口、六个触手支点和中央身体遮罩。补绘身体在运行时按源图多边形分成六条分枝与中央主体：分枝根部留有重叠，由主体盖住接缝；六个支点相位不同，轻微独立旋转，保持短宽根部。未用圆形裁切替代原轮廓，也未重新接入细长触手。

眼镜、镜片、左右瞳孔、闭眼与口型单独绘制，左右眼保留宽度与高度差。鼠标物理坐标按 UI.GetScale 转换，再平滑跟随；绘制时逆变换悬浮、旋转、呼吸缩放和面部偏移，左右眼分别从各自镜片中心看向同一个光标。左瞳最大位移约 13×9 源像素，右瞳约 8×8 源像素，以柔和椭圆限幅保持在镜框内；每约 4.7 秒眨眼。短条正在播报时循环四个嘴型，停顿、结束或跳过后恢复静止。平板以包内图片作两三角形源图取样，拟合参考四角，并叠加完整浅青外边缘；平板独立轻微浮动和摆动。待机悬浮以约 5 秒为一周期上下移动 ±9 源像素，整个人物呼吸缩放幅度约 1.2%；呼吸、漂浮与小幅转头使用独立 UI 时间，战场暂停和对话时仍继续，不改模拟时间或随机数。

这是类 Live2D 的程序分层动画，不包含 Cubism `.moc3`、编辑器绑定工程或语音驱动口型。14 张纹理按 UI 上下文加载一次，在 Stop 中释放，每帧不创建纹理。原素材与补图在资源目录中均可独立维护。

38 项资源/动画检查及 150 项对话/布局检查通过，详情见 `docs/brain-rig-results.json` 与 `docs/brain-advisor-results.json`。分层多边形覆盖身体主体的 99% 以上有效像素；检查同时覆盖变换平衡、纹理缓存与释放、眨眼、四嘴型、视线平滑、暂停时动画和状态不变；新增八个光标方向的瞳孔边界、三个头像尺寸与四个 UI 缩放倍数、悬浮旋转下的视线目标和可见待机幅度检查。`docs/previews/brain/rig-v2-rest.png`、`rig-v2-blink.png`、`rig-v2-motion.webp` 是真实 Lua 绘制代码经离线 SVG 适配器产生的 96 帧预览，不是原生录像。
