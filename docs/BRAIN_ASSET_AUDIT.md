# 脑细胞分层素材审计

审计目标：使用 `assets/image/brain-advisor/production-v1` 的现有分层素材，重建用户最新参考图的形象，再实现独立动作。参考图尺寸为 **390 × 380**。本审计只读取原图，未修改运行代码、原素材或预览会话。

## 造型差异与最少补图

原包的 `body/body_round.png` 是完整无脸身体，包含七根分枝；`body_round_alt.png` 也包含七根分枝。它们可以作为美术风格来源，却不能直接重建参考图的六根分枝、右侧透视和短宽的根部。把完整身体截成椭圆，再接 `tentacles` 下细长独立触手，会丢掉参考图的宽根部和不规则外轮廓。这是前版造型差异的主要原因。

最少需要补生成 **一张无眼、无眼镜、无嘴、无平板的六分枝身体底图**，严格对齐参考图轮廓。身体和六根分枝可在运行时用源图多边形划分，由共同基准位置做轻微弯曲；静止状态必须能拼回原轮廓。现有瞳孔、眼镜、闭眼状态、口型、平板图案和提示特效均能继续使用。独立高亮末梢不是第一轮必需补图。

`tentacles/tentacle_01..08.png` 适合长神经突起的其他角色。用于这张参考图时需要大幅压缩和改变宽度，独立生成匹配身体比拉伸这些素材更可靠。

以下坐标格式均为 **x, y, 宽, 高**，原点在各源 PNG 左上角。主图与邻片边界使用 alpha > 100 的连通区域交叉检查。

## 390 × 380 参考布局

以下是在参考图中测得或按轮廓估计的基准位置。整个人物缩放时统一缩放这些坐标，不能分别任意摆放。

| 部件 | 基准位置/大小 |
|---|---|
| 左镜框外接框 | `165, 188, 81, 89` |
| 右镜框外接框 | `263, 179, 56, 80` |
| 鼻桥 | 约 `240, 216, 29, 16` |
| 左瞳孔 | 实测 `204, 217, 17, 36`，中心约 `(212,234)` |
| 右瞳孔 | 实测 `280, 207, 12, 33`，中心约 `(285.5,223.5)` |
| 口型 | 说话时可置于约 `(244,275)`，小尺寸，部分被平板遮住；待机隐藏 |
| 主体无脸区域 | 约 `(131,141)-(324,310)`，保留斜向不规则轮廓 |
| 六个分枝末梢中心 | 上 `(211,20)`；左上 `(101,100)`；左 `(21,218)`；左下 `(85,334)`；下 `(181,363)`；右上 `(336,158)` |

右镜宽度约为左镜的 69%，眼睛中心高度错开约 11 像素。两镜做成等大、水平对齐，会重新造成面部与参考图明显不同。镜片内侧使用接近脸色的淡白色眼球，瞳孔位移应很小。

## 平板的源图顶点

`tablet_screen` 主屏可用于拟合的近似顶点（左上、右上、右下、左下顺序）：

`(4,24), (109,0), (102,76), (0,108)`。

这些是裁切后的可见边界，不是完整平板四角。主屏的左侧与右上角在 PNG 边缘已截断。三角形采样时保留主图窗口并做目标平板轮廓裁切，避免采到 x129 以后的邻片。

`tablet_base` 对应的近似四角更完整：

`(21,22), (127,-2), (109,74), (2,104)`。

右上角仍略超出源画布。推荐把 base 作为外壳，screen 只提供屏幕图案。父任务使用的目标四角为 `(264,276), (384,244), (345,330), (207,359)`；保持这个倾斜大平板，可避免前版小平板和位置偏下的差异。

## 验收重点

先验证静止拼装的身体六分枝、左右眼透视、瞳孔和大平板与参考图一致，再加入呼吸、短幅摆动、瞳孔追踪、眨眼和口型。不要用持续大幅摇摆掩盖静止轮廓错误。既有原始素材应完整保留，新增身体底图单独存放并记录来源。
