## 可玩循环

肺部生成氧气 → 红细胞实际沿组织通路与血管运到心脏 → 用运抵氧气领取心脏已有葡萄糖 → 沿原通路运回肺部 → 就近恢复白细胞作战储备。

心脏葡萄糖初始库存 160；运氧领取采用 1:1 交换，领取扣库存，运回抵达才增加肺内库存。没有全地图瞬间共享、跨器官传送或无限生成葡萄糖。运送中的货物保留在红细胞 cargo，手动指令会接管运输，恢复自动运输不会重复装载。缺路时等待并重试。

感染灶也消耗同一份肺内葡萄糖。营养不足便暂停繁殖；运输恢复后既能给白细胞补给，也可能使未清除的感染灶重新繁殖。氧气、葡萄糖、储备与感染均按模拟时间更新，战术暂停时不推进。

## 操作

- 空格或原工具栏继续/暂停。暂停中隔离和运输命令会排队，继续后执行。
- 框选白细胞，点击感染灶或病毒攻击；保留原移动、进攻移动、停止与编队操作。
- “隔离右肺”同时关闭右肺两个已登记关口，所有阵营及运输都停止穿越；已有库存仍可使用。细胞正在穿过膜口时拒绝关门，避免困在通行中间。
- “解除右肺隔离”恢复正常关口权限，运输自动重试。健康/失守关口原有的病原体通行规则仍生效。
- “恢复自动运输”让仍存活的原运输红细胞继续循环，保留手动阶段携带的物资。
- “肺部前线”“心脏补给点”“定位运输队”切换观察位置，“重试防线”重置本遭遇。红细胞往返需要实际行军，可以使用工具栏 2× 速度。

顶部氧气和葡萄糖读数在本模式下明确显示肺内库存。白细胞下方蓝条表示作战储备，低储备变为黄色；面板显示感染、运输和各单位储备。

## 接入与边界

规则主体为 `SystemicBattle`，由既有 OrganTrial 固定步驱动；运输使用 Commands.go / Path / OrganTraffic / CellCollision，隔离进入既有 VascularCheckpoints 通行校验。战斗弹丸使用真实地形扫掠，攻击建筑由弹丸碰撞结算；友方建筑能挡颗粒弹但不受友伤。普通器官战斗也检查组织与血管平面的射界。

Save 保存新增场景状态及实体携带物、储备、关口隔离，恢复时检查数值、单位编号和关口一致性。旧存档没有 systemicBattle 字段时保持旧玩法。重试只清理本遭遇及其遗留弹丸/尸体，保留其他地图单位。

本版只将右肺与心脏接成闭环。全身多器官生产调度、流向与压力、炎症、自动伤兵轮换和全身稳态胜负仍是后续内容。
