# 连续组织地图与缩放画质

2026-10-06。新人体地图及 v4 原尺寸地图使用同一套连续曲线底图，取代远景彩色矩形。人体外缘与组织分层来自相同种子和解剖表面场；器官使用矢量腔室，局部生境由真实地形采样补充为曲线色斑。远景省略微小组织纹理，保留完整人体轮廓、器官、血管与黄色通行口。地图碰撞、资源、迷雾和寻路规则保持原有生成器。

近景复用血管骨架，屏幕内最多补绘 48 个血流装饰和 100 处组织纹理，避免逐格绘制与反复检查管壁。资源插画在较近视角显示；远景保留可选择的胞群标记。细胞继续使用四帧微状态、缓慢旋转和呼吸形变，图片启用 mipmap 与线性过滤；矢量膜线、组织纹理和血管线条按真实 DPR 抗锯齿绘制。位图原画仍有固定分辨率，不能将其描述为无限放大无损。

小地图和全身总览采用相同曲线表面。探索与可见区域缓存为带孔洞的曲线蒙版，单位与资源继续按真实迷雾状态过滤。镜头变化不改变存档、随机数或资源分块。

人体轮廓在进入新世界时准备一次，隔离 Lua 运行中约 0.27 秒；平移与缩放复用结果。每帧地形采样最多 64 次，局部色斑缓存最多 64 块，近景纹理缓存最多 4096 点。色斑在准备完成后逐步淡入；送入 NanoVG 前裁剪屏幕外曲线，避免近景对完整人体进行巨大尺度的曲线细分。

## 验证与限制

37/37 组检查通过：[汇总](smooth-results.json)。覆盖曲线孔洞、裁剪、DPR 1/2/3、全身/近景/平移绘制预算、存档不变、单位可选与敌方迷雾，以及 22 组玩法和 7 组管壁回归。所有用户 Lua 脚本语法加载通过；新增 LSP 错误为 0，保留原有验收与 AI 类型诊断。

同样的 1920×1080、种子 73、镜头位置，Lua 5.4 与空 NanoVG 后端中：近景绘制工作从约 35.3 ms 降至 2.6 ms，每帧填充从 5311 次降至 977 次；0.5 倍约 1.5 ms，0.24 倍约 1.6 ms。参见 [性能记录](smooth-performance.json)。这些是隔离 CPU 工作量与绘制调用统计，不是原生帧率；局部采样仍在逐步完善。

本轮首次窗口预览在 READY 后发生 Metal 图形缓冲区 SIGSEGV。随后增加屏幕外曲线裁剪并通过上述离屏与几何检查。最新修改尚未重新打开窗口测试，原生稳定性与实际缩放帧率仍未确认；已请求是否重开窗口，按项目规则不自动恢复退出的预览。原有天空盒资源缺失也仍使预览整体就绪检查失败。
