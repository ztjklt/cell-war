# 巨人体内版本验收

2026-10-05，地图仍为 1024×1024，存档 v3。人体布局与手绘素材为原创幻想设定。

## 地图与美术

新增 `Anatomy.lua`，将地图组织为脑域、胸部肺泡与心肌、腹部肝叶与肠道、肢体骨质与骨髓。人体组织轮廓和血管分支取代大陆海岸；器官区域保持识别性，局部组织边界、炎症、坏死与资源随种子变化。三阵营出生点至中部保持通行血管，血浆深流阻挡地面移动。

16 种组织各有颜色与绘制细节：肌纤维条纹、胶原曲线、肺泡膜环、神经分支、骨孔、肝叶单元、脂滴和菌群。`BodyArt.lua` 绘制全部资源、十四种可建造膜囊、感染体与器官地图标注；`Cells.lua` 保留六类动态细胞。地面格之间增加绘制重叠以消除抗锯齿接缝，血管随模拟时间脉动，暂停时冻结。

资源改为蛋白质、钙质、盐晶、胶原、铁质、葡萄糖、脂质、基因片段，内部资源键与费用规则保持一致。昼夜和季节参数分别以活跃/过渡/休息及四种稳态周期呈现，仍是一日六分钟、每期八天；原来的寒冷、潮湿、热压力与火灾规则用来表达幻想人体内的危机。

## 验证

- Lua 5.4 全部游戏源文件通过语法加载。
- `Acceptance.run()` 17 / 17 组通过，包括采集运输、施工、生产、人口、周期生存、AI 迷雾、输入隔离、跨区寻路、稀疏存档、器官布局及旧地图兼容。
- 五个种子 `1,7,73,2026,183947` 均覆盖 16 种组织；检查脑域、肺泡区和肝域有对应组织，中央血管及出生通道可通行。
- 使用备份中的真实 v2 代码生成存档，v3 恢复后抽查 4,096 个地图点，拓扑保持一致；时间、随机数、资源数量及再保存恢复检查通过。人体地图独立持久化地图类型，拒绝损坏类型。真实 v1 存档也完成迁移、采集命令索引转换、二次恢复及继续运行验证。
- 同一世界种子 11 连续运行 720 秒、7,200 个固定步。测试驱动通过正常指令发展玩家，两个敌方使用正式 AI。三阵营均存活，人口 40、30、28，科技 T3、T2、T2，最多 5 个寻路任务、311 个总实体。Lua 回收后内存约 34.8 MiB，不含原生引擎或纹理。原始数据见 [body-results.json](body-results.json)。

## 原生本地预览

实际窗口已显示人体内域全图、组织图例及脑域/肺泡区/心脏/肝域/肠道/骨髓标记，并验证总览切换与返回胞群。胞群、荧光腺、营养资源和六类细胞均使用新美术。实测选择工细胞采集蛋白束，运输交付后蛋白质库存从 160 增至 544，首日引导进入荧光腺建造步骤。胞群蓝图卡片显示新结构图标与蛋白质/钙质/胶原费用，地面格接缝已消除。桌面普通开局 HUD 观察约 58 FPS，不作为满人口手机性能结论。

CLI 的默认天空盒资源缺失仍使 `preview check` 返回失败；该引擎资源错误与 2D 游戏加载状态分开记录。真实画面与 Lua `READY | world=body` 日志用来确认加载，本地没有云存档连接。

此版本没有远端提交/构建，没有手机实测，也没有重跑 v1 的 64 天长测。历史记录见 [v2 大陆扩展](EXPANSION.md) 与 [v1 验收](VALIDATION.md)。

## 连续移动与血流美术更新

细胞的原位置每 0.1 秒跳变一次，抵达每个路径点还会空等一次更新。本轮保留固定玩法步长，将显示坐标按逐帧余量插值，沿本步实际经过的路径段移动。寻路只在完整可通行的线段上简化节点；移动消耗剩余距离跨越节点，并增加 0.14 秒响应的加速、临近目标减速和按秒封顶的柔和避让。点击和框选与显示位置一致，视觉数据独立于存档。

整个局部地图使用相邻组织颜色过渡、跨格柔软膜层、连贯微血管和低密度漂浮红细胞；细胞膜改为平滑曲线并加入轻微浮动、运动形变。血流和组织脉动随连续模拟时间变化，暂停和菜单时冻结。红细胞循环有渐隐，镜头移动不重置粒子，视觉绘制不消耗玩法随机数。组织色缓存最多 32,749 个槽。保留原器官布局、16 种组织、战争迷雾和地形通行规则。

当前 20 / 20 组 Lua 回归通过。新增检查涵盖 30 / 60 / 120 帧下的连续匀速、正常及两倍模拟速度、暂停、状态替换、密集路径点无空等、墙角阻断、沿拐角插值和移动中存档恢复，结果在 `fluid-results.json`。同一 Lua 世界绘制函数通过离屏 SVG 适配做了画面检查；该图片不含 HUD，也不代表原生截图或真实帧率。原生本地预览已刷新，新 Lua 模块加载及 READY 日志用于验证启动。CLI 的已有默认天空盒资源缺失仍使 readiness 检查失败；当前桌面手感、实际 FPS 和手机性能没有自动化视觉验收。
