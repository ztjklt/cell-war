# 红细胞与中性粒细胞动画接入

- 角色：worker 使用红细胞背包造型；neutrophil / spear 使用持枪中性粒细胞造型。
- 红细胞：静止、八帧移动、氧气/葡萄糖搬运、小锤建造/维修、受击和阵亡。连续伤害不会把受击动画反复重置到第一帧，保留中段忍痛表情。未携带氧气或葡萄糖时使用空包素材。
- 中性粒细胞：静止、八帧移动/开枪/受击/阵亡，四帧杀菌颗粒弹。枪口锁定当前敌人，朝右时镜像。
- 开枪：射程暂设 6 格；伤害、血量和攻击间隔保留原配置。前摇 .35 秒后发弹，速度 10 格/秒，命中才结算伤害。转向、换命令、死亡、遮挡和友军判定复用游戏规则。
- 阵亡：立即移出可交互实体，保留独立的显示快照。八帧倒地动作持续 1.3 秒，末帧闪两次，1.82 秒完全消失，显示快照随后清理。死亡显示不参与碰撞或选中。
- 图集按 NanoVG 上下文延迟加载并在关闭时释放。保留现有逻辑像素 / DPR 模式。
