# 右肺上支检查（2026-10-19）

对照注册底图与当前候选气管轮廓，右上斜支边缘发现两处微小钩状内凹；浅色高光与气管实体色不同，被浅黄阈值剔出，自动轮廓因此向内扣、产生近闭合小钩。两处对应源坐标约 (452.8,338.9)、(450.2,342.3)。

细节对照第 1、2 行展示误识别小钩；第 3 行展示竖直主干一个较大的台阶，底图自身也有该宽窄变化。真实主分叉之间的 V 形凹谷不应填平。

建议对小钩按外侧连续实体边缘重描，过滤小于实际几何尺度的高光缺口，保留主干实际宽窄及分叉结构。这次仅检查与定位，未修改候选轮廓、用户草稿或运行时碰撞。右侧预览切到右肺气管，放大至约 314%。
