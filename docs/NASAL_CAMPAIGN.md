# 鼻腔战役 v6

新开局为鼻腔守卫。沿用同一个人体、随机种子与实体世界；鼻腔胜利后部队保留，可以继续在鼻腔活动。咽喉、双肺、肠道和血流事件目前显示「尚未开放」，不会进入空关卡。旧存档继续沙盒玩法。

## 本轮玩法

鼻腔位于人体面部投影，三块共享边界的组织多边形依次为入口黏膜、鼻甲通道、后鼻屏障。入口开场感染，其余区域免疫控制。初始 6 个白细胞、2 个血小板，从后鼻侧血管调入口附近出场。可以立即向入口反攻。

当前地形已扩为 216×160 格的双侧黏膜展开图，包含左右鼻腔、鼻前庭、鼻中隔、每侧上中下鼻甲、鼻道、嗅区、鼻底和后鼻孔。鼻甲与鼻中隔是实际障碍，绕行道路和血管共用真实寻路；详细设计与当前验收见 [鼻腔地形](NASAL_TERRAIN.md)。

占领按存活战斗单位的位置自动计算，双方在场暂停，无人在场保留。控制值从感染 -100 经中立 0 到免疫 +100；单人完整翻转需要 40 秒，3 人以上 20 秒。只有后鼻完全达到 -100 才判失败，先于同一步的胜利判断。

病毒在模拟时间第 10、45、90 秒发起 6、8、10 个单位的三波入侵，从入口依次推进尚未完全感染的区域。新地形第一波进入右鼻腔，第二波进入左鼻腔，第三波两侧同时进入；每波单位间隔 0.7 秒。旧鼻腔记录保留原单入口路线。

补给初始 4、上限 6，每 10 秒增加 1。调援消耗 2、冷却 20 秒，3 秒后从后鼻固定位置加入两个白细胞。命令执行时验证事件、补给、冷却和人口；在途单位预留人口，人口上限 40。暂停可排队，两倍速度只增加固定模拟步数量。

三波全部进入、病毒清零、全部区域免疫控制并稳定 20 秒即胜利。鼻腔事件隐藏经营入口，关闭饥饿、温度、应激与旧沙盒胜败规则。事件失败后模拟停止，「重试本次事件」恢复开始检查点，包括部队、资源、时间、随机状态、命令、此前完成记录与开放状态。

## 代码与后续接口

| 模块 | 职责 |
| --- | --- |
| CampaignData | 战场几何、五事件路线、波次、补给和奖励参数 |
| Territory | 区域包含关系、存活单位计数、控制与争夺状态 |
| Reinforcements | 补给、冷却、人口预留和延迟调入 |
| Campaign | 开始、检查点、成功、失败、重试、解锁、奖励、随机候选位置 |
| NasalArt | 与玩法共用多边形的黏膜染色、褶皱、区域边界与地图标识 |
| NasalTerrain / NasalTerrainAcceptance | 双侧鼻腔、鼻甲障碍、局部血管布局与导航/战斗验收 |
| NasalAcceptance | 隔离的玩法回归，不写实际云槽位 |

`Simulation.new(seed, mode)` 默认 `campaign`；回归或旧玩法使用 `sandbox`。`Commands.submit(s, {kind="reinforce", faction=1})` 统一经过命令队列。鼻腔限定在 `Campaign.allowed` 中，由命令、出生、建造、地面和寻路检查共同执行；查看全图不会开放组织。原血管壁、膜通行口和碰撞规则继续生效。

后续通过 `CampaignData.stages` 和 `Campaign.start / succeed / fail / unlock` 接入，新增事件还需要对应几何、规则和美术。随机事件候选接口 `Campaign.randomCandidates` 仅在前五事件完成后启用，返回已开放组织；目前不会产生随机战斗。第五事件配置开放全人体。

存档 v6 增加模式及战役状态：阶段、完成记录、奖励记录、开放区域、波次和待入侵单位、区域控制、稳固计时、补给、调援队列及事件检查点。检查点排除自身检查点字段，读取时拒绝递归嵌套。恢复不调用事件开始或奖励逻辑。v1–v5 忽略战役字段并保持各自地图拓扑，重新保存为 v6 沙盒。

新鼻腔记录在战役中保存 `terrainVersion=2`，检查点必须使用相同地形版本。没有该字段的旧 v6 鼻腔记录继续原 120×64 地形、原出生位置及通路，重试也不会搬到新地形。
