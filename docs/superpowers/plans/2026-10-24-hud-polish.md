# 战斗操作区美术与反馈 Implementation Plan

> **For agentic workers:** 在当前工作区执行，保留既有/并行修改。适用 superpowers:executing-plans 的实现与独立审查流程；不提交、合并或推送。

**Goal:** 沿用左肺任务卡的 GPT 细胞画风，完善资源栏与选中面板，使常用操作可见且反馈清楚。

**Architecture:** 两张 GPT 无字底图由轻量 PanelContainer 绘制，原生容器负责文字/按钮。沿用现有资源计数动画和已存在的按钮动效辅助；选中反馈由面板自身触发。原有细胞精灵直接复用。

**Tech Stack:** Godot 4.6 / GDScript / Control / 内置 image_gen。

**Spec:** 用户要求继续美化 UI、使用 GPT 生图、模仿原版无腿无脚细胞并加入动效。范围：左肺首战的资源/选中面板和常用工具按钮；不扩展夺回左肺后玩法。

## Design / choices

- 制作资源条（3:1）和选中面板（2:1）两张透明、无文字、无角色底图，保留奶油中心和细胞膜边缘；使用既有细胞图作风格参考，角色不重新设计。
- 采用底图+原生内容。整张静态烘焙 UI 会失去交互，不采用；重做角色没有必要，直接保留已有精灵。
- 竖屏资源栏放在顾问与小地图之间，以三行紧凑卡片呈现；显示蛋白质/氧气/葡萄糖标签与真实库存，保留地图控制位置。
- 选中面板按实际最小高度定位到屏幕底部，状态与缩放工具一起避让，滚动区保留长详情/命令。
- 资源增减有短促色彩反馈，新局/读档直接显示正确数量；选中变化轻微点亮面板；工具栏与定位按钮沿用已有原生按压动效。
- 这些具体布局选择为本次实现判断，遵循用户连续授权，不重复要求审批。

## Constraints / review focus

- 两张美术保留原稿、提示词、参考与哈希；运行资源完全位于 godot。
- 不增加脚/腿或改变角色设定；不改变经济、战斗、导航或存档格式。
- 动效不能造成重复点击、选中改变、暂停计时推进或读档后的虚假资源变动。
- 360/390/430 竖屏和常用桌面尺寸下，资源与选中信息不能出屏或盖住工具按钮。
- 不覆盖并行图鉴工作；仅复用已存在的按钮动效接口。
