# 左肺任务卡美术与信息呈现 Implementation Plan

> **For agentic workers:** Execute in the current session with superpowers:executing-plans. Keep the existing checkout and do not commit or push.

**Goal:** 将已验证的左肺准备、交战、净化和胜利提示统一为贴合现有细胞画风的 GPT 生图任务卡。

**Architecture:** GPT 制作透明卡片底图和红白细胞合作插画；WarDefenseCountdown 负责原生动态文字、数量、进度和倒计时跳动。保留战斗逻辑和存档格式。美术原稿/提示词保存到 assets，运行副本和哈希纳入 godot。

**Tech Stack:** Godot 4.6.3 / GDScript / Control / TextureRect / 原生 image_gen。

**Spec:** 用户要求“任何改动结合 GPT 生图美化 UI，尤其模仿细胞画风”，并已要求继续执行。此次范围延续上轮说明：先做左肺任务、净化、胜利提示。

## Design

- 直接参考已认可的背包红细胞和紫色三叶核白细胞：深色干净轮廓、凝胶高光、圆润卡通造型。浅奶油文字区与现有 HUD 衔接。
- 一张无字透明底卡 + 一张无字红白细胞合作插画。角色保持比例，文字与进度不烘焙。
- 四阶段：准备倒计时与建设提示；交战显示病毒/要塞数；净化明确缺少哪种细胞及连续 20 秒进度；胜利显示夺回和完成时间。
- 屏幕上方居中，避开工具栏。桌面与窄屏使用同素材排版，所有装饰不阻挡地图输入。保留倒计时跳动，暂停不推进游戏进度。

## Global Constraints

- 保留独立图层、导航规则、战斗数值和现有存档。运行依赖完整放入 godot。
- 使用内置 GPT 生图，原稿、来源、完整提示词留档；不使用代码或 Python 绘图替代生图。
- 当前用户已授权执行；设计记录用于交接，不重复要求确认。
- 不提交、推送或进行远端构建；生成截图留在 test-output。

## Review Focus

- 新局/继续/阶段转换不能残留旧文案、颜色、进度或动画。
- 敌军/要塞计数取本次感染群，净化中断显示真实归零。
- 窄屏文字可读且不盖工具栏，图像比例与透明边缘正常。
- 面板及所有子控件透传鼠标，不影响点选/右键指令。
- 新素材入库和来源哈希可审计，不能只在生成工具目录引用。
