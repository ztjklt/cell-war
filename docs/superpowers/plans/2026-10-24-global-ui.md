# 全局细胞膜 UI Implementation Plan

> **For agentic workers:** 当前工作区实现；保留既有未提交内容。按 superpowers:executing-plans 实现并进行一次独立只读审查；不提交、合并或推送。

**Goal:** 将用户已认可的奶油中心、珊瑚/淡紫膜边、深梅色轮廓和轻微动效推广到全游戏可交互 UI。

**Spec / authorization:** 用户明确要求“应用到全局”“尺寸不一样继续生图”“强化所有游戏里面所有UI”。原细胞无腿无脚，动态文字与操作保留原生；当前画风已经明确认可，无需再次选择风格。

**Architecture:** 生成适合九宫格的方形面板、长按钮、方形指令牌与小型拖动珠。Godot 离线工具只裁切/缩放生成素材并保存来源映射，运行资源完整位于 godot。共享 WarUISkin 提供原生贴图样式和状态；图鉴转用同套表面，保留其原生图标/搜索/播放；封面和径向指令的自绘按钮分别改用生成底图。

**Tech Stack:** Godot 4.6+、GDScript、Theme、StyleBoxTexture、原生 Control/Tween、内置 image_gen。

## Scope / design

- 普通、主要、选中、悬停、按下、禁用、焦点状态使用相同表面系统，颜色与微动效区分状态。
- 覆盖封面四入口、存档/设置/帮助/战场/建设生产/运输/器官协作/药品弹窗、主HUD/关卡HUD、环形指令、图鉴搜索/标签/播放控件、顾问提示与生活对话按钮/气泡、原生滑条/滚动条/输入框/下拉框。
- 主封面按钮从投影底座改为细胞膜卡片；复用现有图标及点击后反馈再导航的交互。角色、地图独立图层、事件、经济、战斗与存档规则仍按既有实现。
- 生活对话以奶油/淡紫气泡区分来信与本人，保留原生文字、滚动、回复结算与手机的布局职责。
- 美术底图按用途生成；九宫格只拉伸安静内区和直边，保留圆角与线宽。动态文字不烘焙。
- 尺寸检查覆盖桌面、平板、竖屏和横屏；长文本可换行/滚动，键盘与触控目标可达。

## Review focus

- 动态创建的菜单和过滤后的图鉴卡片不能退回旧风格；原生输入框/下拉弹层/禁用态也必须一致。
- 点击与按压动画不能重复回调、阻挡滚动、改变游戏时间或窃取地图指令。
- 细长按钮、巨大弹窗、方形指令牌保持边框比例；窄屏长文本和多语言标签可达。
- 气泡颜色改变后保留清晰对比与原有回复流程，图鉴搜索/播放/原生弹出菜单保持可操作。
- 所有运行素材可追溯到GPT原稿，禁止将概念截图当成已经完成的全游戏验收。
