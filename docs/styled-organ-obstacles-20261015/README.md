# 精修器官凸起碰撞

按现有器官精修图进行视觉识别和一次性人工审阅标注：153 处凸起，合并为 108 个相交轮廓组件。轮廓为保守近似底面；平面斑纹和投影不作为实体障碍。当前范围包括脑、双肺、肝、胃、胰、双肾、大小肠和膀胱；心脏继续沿用四心腔/瓣膜原有专用碰撞。

原器官外形和图像均未改动。离线从组织地面减去障碍，按小/大细胞半径膨胀障碍，再生成一致的寻路网格与整段移动检测。血管属于独立通行平面，不受下方器官障碍阻挡。图层透视不改变碰撞。

验证：324/324 障碍点拒绝、252/252 穿障直线拒绝并成功求得绕行路线、1873 段路线扫掠通过；33/33 组真实 Commands/Simulation 移动（侦察、工人、大细胞，11 个有新增凸起的器官），27714 步运动检查无穿障。旧存档障碍内位置迁移通过。具体结果以 JSON 报告为准。
