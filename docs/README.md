# 开发文档

《细胞战争》的当前工程位于 [`godot/`](../godot/)，使用 Godot 4.6+ 标准版与 GDScript。运行、修改和验证游戏时，从以下文档开始。

## 当前工程

| 文档 | 内容 |
| --- | --- |
| [运行与开发](../godot/README.md) | 启动方式、玩法入口、操作、代码结构与测试命令 |
| [一致性与验收范围](../godot/PARITY.md) | 迁移依据、已有证据、差异及尚待验证的内容 |
| [封面与角色预览](../godot/COVER.md) | 当前封面构图、交互、素材来源与检查方式 |
| [更新记录](../CHANGELOG.md) | 当前 Godot 工程的重要变化与旧版历史记录 |

## 工具与素材

| 目录或文件 | 用途 |
| --- | --- |
| [Godot 离线工具](../scripts/godot_tools/) | 素材安装、完整性校验与交接打包 |
| [序列帧工具](../scripts/sprite_preview/) | 动画制作、打包与本地预览 |
| [素材原稿](../assets/) | 美术原图、动画帧、生成提示词与编辑记录 |
| [运行素材](../godot/assets/) | Godot 工程实际加载的资源 |
| [数据与来源清单](../godot/data/) | 游戏数据、素材登记与迁移来源哈希 |
| [回归检查](../godot/tests/) | 规则与交互测试；`fixtures/` 保留冻结的原版绘制基准 |

运行游戏只需 Godot 工程内的代码、场景、素材与数据。根目录工具用于离线制作和校验；依赖与使用方法以[运行与开发](../godot/README.md)为准。
