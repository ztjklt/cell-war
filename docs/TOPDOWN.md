# 2D 正俯视与细胞微状态

> 当前新游戏采用 2048×4096 和存档 v5，见 [半尺寸地图](MAP_SCALE.md)。实际血管与通行口的原型记录见 [VESSELS.md](VESSELS.md)。本文保留上一阶段的验收记录。

2026-10-05。本轮完成游戏显示与输入坐标的正俯视重构，人体世界仍为 1024×1024 个逻辑格，存档格式 v3。

## 画面与操作

- `View.lua` 统一正俯视投影、反投影、拖动平移与可见区域计算。屏幕左右对应世界 X，上下对应世界 Y；缩放保留指针所指的世界位置。
- 地形采用连续组织颜色过渡；取消等距菱形、细胞落地阴影、脚和向上站立偏移。资源绘制为组织内的平面包涵物，设施绘制为膜囊和腺体；防御塔不再抬高。
- 点击、框选、建造预览、血流、战斗连线与小地图视野都使用同一套正俯视坐标。
- 单位沿实际路径连续插值；朝向每秒最多转动 1.5 弧度，移动时叠加轻微摆动和膜形变。动画依赖模拟时间，战术暂停或菜单暂停时冻结。

## 细胞素材

风格为接近正常细胞、具有两只小眼睛的半写实生物插画，保留细胞膜、细胞核、细胞器。六种可控制细胞各有四幅 GPT 生成的微状态图片，第四帧包含轻微眯眼。敌方使用同一图集与阵营膜色，中立感染体使用无腿的膜形绘制并带小眼睛，漂浮红细胞也带小眼睛。

最终透明图集为 `assets/image/cells_topdown_microstates.png`，1024×1536 像素、四列六行；JSON 记录帧矩形、中心和源图裁切位置。由于生成图的行距不等，按每个细胞的透明轮廓定位后裁切，统一中心与尺寸再拼接，避免切断细胞或相邻帧串入。

游戏以 3.2 秒循环播放四帧，并混合相邻帧和微幅形变。世界与 UI 各自初始化一次图集句柄，退出时释放；不逐帧创建图片。提示词保存在 `assets/image/cells_topdown_prompts.json`。Maker GPT 图片接口曾返回 `INSUFFICIENT_BALANCE`，未交付图片且未重试；最终素材由会话内置 GPT 图片生成工具制作并保存到项目。

## 验证与证据范围

- 所有游戏 Lua 文件通过 Lua 5.4 语法加载；22/22 组回归通过，结果见 `topdown-results.json`。
- 新检查覆盖屏幕方向、投影往返、不同窗口与缩放比例、平移、指针缩放锚点、裁剪边界、动画暂停、帧循环、微幅形变和缓慢转向。原有采集、运输、建造、生产、战斗、AI、存档与连续路径检查继续通过。
- `previews/topdown-world.png` 由实际 `Render.draw()` 经离屏 SVG 适配绘制。展示世界种子 73，并加入六种细胞和三种设施作为美术检查样本；不是用户存档，也不是原生窗口截图，不含 HUD。
- `previews/cells-liquid-motion.webp` 使用实际 `Cells.draw()`，展示四幅原始微状态在缓慢漂移、旋转与形变下的动画。预览中的插值帧不是额外生成的静态原画。
- 本地预览已自动刷新，Lua 日志确认图集在世界与 UI 上下文加载，以及 `READY | view=topdown2d`。CLI 的既有默认天空盒资源缺失继续使 readiness 检查失败；原生窗口手感、桌面 FPS 与手机性能未完成视觉验收。
