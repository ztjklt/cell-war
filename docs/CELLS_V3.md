# 红细胞、白细胞与血小板

三张透明 PNG 由 OpenAI 内置 GPT imagegen 生成，原图保持不变。完整提示词与透明边界测量保存在 `assets/image/cells-v3/generation-prompts.json`。

- 红细胞（worker）：红色双凹圆盘，负责采集、运输与建设。
- 白细胞（spear）：乳白膜与紫色分叶细胞核，基础近战兵种。
- 血小板（scout）：小型金黄色圆角碎片，快速侦察。

没有手脚。动画采用模拟时间控制的连续旋转与小幅收缩，暂停时冻结。进阶兵种沿用白细胞轮廓，通过尺寸与内侧标记区分。

`Data.cellRadii` 为碰撞和绘制的共同尺寸来源。`CellCollision` 使用圆膜扫掠、接触后切向滑动、拥堵短程绕行和约束分离。单位出生寻找空位；无法放置时保留生产队列。编队间距按所选最大半径计算。旧存档恢复时分离重叠细胞。

`Motion.position` 将同一帧的插值位置整体约束，缓存结果用于绘制和点选；不修改模拟位置、随机数或存档。透明素材按实际径向边界缩放，呼吸不会放大出碰撞圆。

测试：`.maker/cell-qa/check.py`，结果：`docs/cell-collision-results.json`。覆盖初始三类细胞、120 个同点混合单位、快速扫掠、敌我对向运动、所有插值帧、编队、密集出生与生产、旧存档迁移、600 步真实模拟和膜壁约束。
